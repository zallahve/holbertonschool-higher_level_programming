# Python - Exceptions

This project covers Python exception handling using `try`, `except`, `else`, and `finally`.

## Learning objectives
- Understand what exceptions are and why they are used
- Handle errors safely with `try/except`
- Raise exceptions when appropriate
- Write functions that behave correctly on invalid input

## Files
- `0-safe_print_list.py`: Prints `x` elements of a list safely and returns the number of elements actually printed.
